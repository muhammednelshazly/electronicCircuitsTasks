# Digital Logic Circuits – Proteus Simulations

This repository contains a collection of digital logic circuit simulations implemented using Proteus.

## Included Circuits

- Parity Bit Circuit
- Half Adder Circuit
- Full Adder Circuit
- Subtractor Circuit and Applications
- 8-Bit Adder Using 74HC283
- 4-Bit Comparator from Scratch
- 2-Bit Comparator Circuit
- Decoder Circuit
- Encoder Circuit
- Multiplexer Circuit
- Demultiplexer Circuit
- S-R Latch Circuit
- R-S Latch Circuit
- D Latch Circuit
- J-K Latch Circuit

## Project Contents

Each task may include:

- Proteus simulation file
- Circuit screenshot
- Boolean expression
- Truth table
- Documentation report

## Tools Used

- Proteus Design Suite
- Digital Logic Gates
- 74LS / 74HC Logic ICs
